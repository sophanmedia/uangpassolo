Pengaturan 1 Database Bersama (uangpassolo-33f3b)

Sistem 1 Database Terpusat Aktif!

Aplikasi ini sekarang dikunci hanya ke satu database (uangpassolo-33f3b). Setiap orang yang membuka link aplikasi dari HP atau perangkat mana pun akan langsung melihat daftar tamu dan nominal yang sama persis.

Pasang Rules Ini di Firestore Database → Tab "Rules" 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Mengizinkan semua orang yang membuka aplikasi melihat & menginput ke 1 database yang sama
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Cara Memasang Rules di Firebase Console:

  1. Buka Firebase Console → Firestore Database → Rules.
  2. Hapus kode lama, tempelkan (Paste) kode Rules di atas, lalu klik tombol Publish.
